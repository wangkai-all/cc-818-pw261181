# MixLens · 盲源分离信号数据分析台

一个**从零实现、零第三方运行时依赖**的本地 Web 应用：用确定性合成序列模拟多个传感器对若干未知真实来源的混合，完成量纲恢复、白化、秩/常量/缺测诊断、FastICA、顺序/符号/尺度匹配、混合重建、后续段固定系数检验、通道换位重标定、已知来源注入和多起点稳定性比较。

不使用外部音频、仪器文件、CDN、NumPy/SciPy 或数据库。Python 端仅使用标准库，前端是原生 HTML/CSS/JavaScript 和 Canvas。

## 运行

```bash
python3 server.py
# 打开 http://127.0.0.1:8000
```

也可以：

```bash
npm start
```

环境变量：

- `PORT`：默认 `8000`
- `HOST`：默认 `127.0.0.1`
- `MIXLENS_DEBUG=1`：输出 HTTP 日志

```bash
python3 -I tests/test_core.py -v
```

```bash

```

测试覆盖：

- 独立非高斯来源应高相关恢复且高 R² 重建；
- 相关来源可以高 R² 重建但不能可靠恢复真实来源；
- 秩不足、常量通道、缺测区诊断；
- 通道换位后“直接套用失败、显式重标定恢复”；
- 已知注入来源恢复；
- 通道屏蔽；
- 顺序和符号匹配不变性；
- 内置反例审计无关键失败。

## 网页功能

1. **诊断优先**：样本/通道维度、每通道均值/SD/缺测区间、常量通道、协方差特征值、有效信号秩和条件数。
2. **量纲与白化**：先按训练段均值和标准差恢复原始单位，再做对称特征值白化；导出的 `A_raw_original_units` 可回到传感器原单位。
3. **分量展示与真值匹配**：用最优二分分配匹配估计分量和合成真值，再校正符号及最小二乘尺度。
4. **混合重建**：训练段拟合 `A = X Yᵀ (Y Yᵀ)⁻¹`，展示观测、重建和残差，并给每通道 R²/NRMSE。
5. **后续段固定关系**：白化、ICA、混合矩阵均只在训练段拟合，后续段固定使用。
6. **通道换位**：模拟后续段两个通道交换；可对比未重标定结果和显式排列均值、尺度、白化矩阵列、混合矩阵行后的结果。
7. **通道屏蔽与时间段**：复选框屏蔽通道；四个滑杆设置训练段和后续检验段。
8. **已知来源注入**：注入脉冲、扫频或方波已知源，选择强度和空间耦合样式，检查是否能恢复。
9. **多起点稳定性**：多个确定性随机起点；所有结果先做顺序/符号匹配，再生成两两稳定性矩阵和叠加图。
10. **反例核对**：一键运行独立、相关、高斯、秩不足、常量、缺测和换位场景。
11. **导出**：
    - 分量 CSV：时间、观测、原始分量、真值、匹配到真值坐标的估计分量；
    - 真实参数 JSON：种子、真实混合矩阵、通道增益/偏移/单位、噪声、注入参数、估计矩阵、匹配和指标。

## 方法与关键约定

### 白化和 ICA

对在用通道的训练段完整样本：

1. 计算训练均值 `μ` 和总体标准差 `σ`；
2. 标准化 `Xs = diag(σ)⁻¹ (X - μ)`；
3. 计算协方差特征分解；
4. 按有效秩保留特征方向，构造 `Z = D^-1/2 Eᵀ Xs`；
5. 使用 tanh 非线性的对称 FastICA 和 Jacobi 特征分解实现的对称正交化。

缺测时只使用所有在用通道均完整的训练时刻；不会在诊断前静默插值。

### 顺序、符号、尺度不唯一

ICA 分量 `Y_i` 与真实来源之间存在：

- 排列不确定性；
- 符号不确定性；
- 尺度不确定性。

应用对 `|Pearson r|` 做最优一一分配，用有符号相关确定符号，并用最小二乘增益把估计分量映射到真值坐标。跨起点比较同样先匹配，因此翻转不会被显示成“来源改变”。

### 重建好不等于来源对

相关来源违反独立性假设，高斯来源缺少高阶可辨识方向，秩不足时观测只包含低维来源子空间。这些场景中仍可能有很高的观测重建 R²，但真实来源匹配分数低或理论上只能确定旋转子空间。界面会保留“部分匹配/不可辨识/高斯旋转不确定”等状态，不提供无证据的物理名称。

## HTTP API

### `POST /api/analyze`

请求体是 JSON 配置，主要字段：

```json
{
  "scenario": "independent",
  "seed": 818,
  "n_samples": 1600,
  "n_channels": 4,
  "n_sources": 3,
  "noise": 0.018,
  "visible_channels": [0, 1, 2, 3],
  "train_start": 96,
  "train_end": 880,
  "eval_start": 960,
  "eval_end": 1504,
  "component_count": "auto",
  "n_starts": 6,
  "swap_enabled": false,
  "swap_channels": [0, 1],
  "injection": {
    "enabled": false,
    "kind": "pulse",
    "amplitude": 0.9,
    "spatial": "uniform"
  }
}
```

### `GET /api/audit`

运行内置小型反例套件并返回每项检查和指标。

## 局限

- 这是教学/实验型实现，矩阵规模按少量传感器和来源优化，不适合大规模生产数据。
- 有效秩使用相对特征值阈值和合成数据噪声底；真实数据需要结合业务噪声与奇异值拐点判断。
- 分箱互信息是依赖性的粗略诊断，不替代严格的独立性检验。
- 对近似高斯来源，即使某个有限种子恰好匹配真值，也不应解释为轴方向已被唯一识别。
